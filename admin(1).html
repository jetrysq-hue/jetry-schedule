Підключення до GitHub

Токен зберігається лише в цьому браузері. Нікому його не передавайте.

  1. GitHub → ваш аватар → Settings → Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → ваш репозиторій з розкладом.
  4. Repository permissions → Contents → Read and write.
  5. Generate token, скопіюйте його й вставте сюди.
